# TS-11 adversarial review

Two story statements were narrowed rather than encoded as misleading guarantees.

First, a pure hash cannot keep an Experiment Assignment stable after arbitrary weight changes. The
function selects the initial variant; lifecycle stability comes from persisting that first assignment.
Its no-reshuffle property applies when existing weights retain their proportions while a new variant is
added.

Second, disclosure is not recognised or stripped by matching a customer-text line. It is a typed
system annotation and is absent from the compared body. This prevents both metric inflation and the
possibility of deleting genuine customer prose that happens to resemble disclosure copy.

Cost is attributed to each Provider Attempt, including failed, repair, retry, or fallback calls—not to
an aggregate Generation shortcut.
