# TS-09 review

## Behavioral evidence

- Every rendered proposition has a Claim and every Claim is rendered.
- Every Claim has a versioned reference to an allowlisted Assertion or permitted context fact from the
  same Review Session.
- Evidence kind, semantic identity, and polarity must agree structurally; a rating cannot support an
  experience fact and a negative Fact Option cannot be rendered positively.
- Reformat and Condense add no Claim; Condense must become shorter.
- Expand preserves the exact source Claim set and becomes longer.
- Revise Wording preserves the source Claim set; its presentation instruction is not evidence.
- Paraphrase uses reviewer-text Assertions from the exact immutable Source Text Revision.
- Resample uses the originating request grounding set rather than the previous sample's realized Claims.
- Derived Claims retain original Assertion/context grounding rather than relying on a parent Claim id.

Rejected candidates return no Draft or candidate wording through this safe result.
